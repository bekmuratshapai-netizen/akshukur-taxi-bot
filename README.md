# Такси-бот для Акшукура (прототип)

Простой рабочий бот на aiogram 3: клиент оформляет заказ через личку,
заказ падает в группу водителей с кнопкой «Взять заказ». Первый нажавший
получает контакты клиента, у остальных заказ пропадает.

## 1. Создать бота

1. В Telegram написать **@BotFather** → `/newbot` → задать имя.
2. Скопировать выданный токен.

## 2. Создать группу водителей

1. Создать обычную группу Telegram, например «Водители Акшукур».
2. Добавить бота в группу.
3. **Отключить Group Privacy у бота**, чтобы он видел команды:
   @BotFather → `/mybots` → выбрать бота → *Bot Settings* → *Group Privacy* → *Turn off*.
   (Для этого бота это не критично, т.к. он только шлёт сообщения в группу
   и слушает нажатия кнопок — но лучше отключить сразу, если позже добавите
   команды от водителей.)
4. Узнать `chat_id` группы: добавить бота, написать в группе `/myid`,
   бот ответит числом вида `-1001234567890` — это и есть DRIVERS_GROUP_ID.

## 3. Настроить проект

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Открыть `.env` и вписать:
```
BOT_TOKEN=токен_от_BotFather
DRIVERS_GROUP_ID=chat_id_группы (со знаком минус)
```

## 4. Запуск

```bash
python bot.py
```

Бот стартует через polling — этого достаточно для села и небольшого
числа заказов. Когда нагрузка вырастет, можно перейти на вебхук.

## 5. Как это работает

- Клиент: `/start` → «🚕 Заказать такси» → откуда/куда/телефон → подтверждение.
- Заказ сохраняется в `taxi.db` (SQLite, создаётся автоматически).
- В группу водителей уходит сообщение с кнопкой «🚖 Взять заказ».
- Первый нажавший водитель атомарно (через `UPDATE ... WHERE status='new'`)
  забирает заказ — гонки исключены даже если два водителя жмут одновременно.
- Клиенту приходит уведомление, кто принял заказ.
- Сообщение в группе редактируется — кнопка исчезает, виден водитель.

## 6. Что можно добавить дальше (по мере роста)

- Кнопка «❌ Отменить заказ» у клиента, пока заказ не взят.
- Рейтинг/список активных водителей, ограничение по сменам.
- Геолокация вместо текстового адреса (`request_location`).
- История заказов клиента (`/history`).
- Переход с polling на webhook + деплой на Railway/Render, если ботов
  и заказов станет много.
- Панель водителя: «На линии / не на линии», чтобы не слать заказы всем.

## 7. Деплой (когда прототип обкатан)

Бесплатные варианты для старта:
- **Railway** или **Render** — задеплоить как worker-процесс, `BOT_TOKEN`
  и `DRIVERS_GROUP_ID` вписать в Environment Variables.
- Для устойчивости базы данных при деплое лучше перейти с SQLite-файла
  на встроенную Postgres-БД хостинга (когда заказов станет много).
